🌐 Frontend Senior

El track experto sobre la plataforma web. No es otro curso de frameworks: es entender la máquina sobre la que corren todos.
"El CSS no se rompe: se pudre. Nadie borra una regla por miedo."

8 módulos Navegador · V8 · Red Web Vitals · INP CSS moderno · A11y experta

📖 Para quién es

Para el que ya construye interfaces y ahora necesita explicar por qué: por qué la lista scrollea con tirones, por qué el bundle pasó de 180 KB a 940 KB, por qué el sitio da 100 en Lighthouse y los usuarios se quejan igual, o por qué el dropdown "accesible" no lo es.

Pre-requisito real: el Curso de Frontend completo (M00–M13). HTML, CSS, JS, DOM, async y algo de React tienen que estar cómodos.

Cómo se relaciona con el resto: este track es la plataforma. El Track Senior transversal cubre arquitectura, testing, observabilidad y liderazgo; el React Senior cubre ese ecosistema. Los tres se complementan sin pisarse.

⚙️ Actualizado a septiembre de 2026. FS4 enseña INP, que reemplazó a FID como métrica de interactividad y es bastante más exigente. FS5 da el CSS que por fin es usable en producción — @layer, :has(), container queries, view transitions. Y FS7 cubre la generación de herramientas en Rust y Go que cambió los tiempos de build por completo.
